Class: Philox

numpy-bitgens.Philox(seedopt, optionsopt)

Philox 4x64-10 counter-based generator (Salmon et al., 2011; numpy Philox). advance(n) jumps n blocks of four outputs in O(1), and different keys give independent streams.
