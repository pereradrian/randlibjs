Class: FunctionBitGenerator

bit-generators.FunctionBitGenerator(fn)

Wraps any function returning doubles in [0, 1) (e.g. Math.random) as a bit generator. Its state cannot be saved or restored.

Constructor

new FunctionBitGenerator(fn)

Parameters:
Name Type Description
fn function

Function returning uniform doubles in [0, 1).
