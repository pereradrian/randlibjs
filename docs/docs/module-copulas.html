Module: copulas

Copulas: random vectors with uniform margins and a chosen dependence structure. Map each coordinate through any quantile function (stats.<family>(...).ppf) to get dependent variables with arbitrary margins.

Elliptical copulas (Gaussian, Student t) take a correlation matrix; the Archimedean ones (Clayton, Gumbel, Frank) take θ and a dimension and are sampled exactly with the Marshall–Olkin frailty construction. copulaTheta converts a Kendall's τ into the parameter of each family.
